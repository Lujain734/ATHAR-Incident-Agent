Two updates to the existing ATHAR app. Keep all current features and the simulation flow. Do not redesign from scratch.

PART A — Fix layout and bidi issues:
1. Pod cards: the status badge (OOMKilled / CrashLoopBackOff) overflows outside the card. Put it inside the card header as a normal badge (no absolute/negative positioning). Add overflow-hidden and min-w-0 to cards; truncate long pod names with ellipsis and show full name in title attribute.
2. Mixed Arabic/English text renders in wrong order. Rule: Arabic for all labels, headings and sentences. Technical values (pod names, versions, metrics, commands, log lines, alert names, timestamps) go inside <bdi dir="ltr"> or a monospace span with dir="ltr" and unicode-bidi: isolate. Fix the alert banner, timeline items and agent steps with this rule.
3. Remove the small English uppercase subtitles (TIMELINE, INCIDENT ANALYSIS, MEMORY / MiB, PLATFORM OPERATIONS, CLUSTER / NAMESPACE) or replace them with short Arabic text. One language per label.
4. Wrap the memory chart and log/code blocks in dir="ltr" so time flows left to right. X-axis labels: "-2m", "0", "+2s"... no Arabic word on the axis.
5. Memory progress bars must fill from the start correctly in RTL.
6. Timeline order fix: deploy event → memory rising → OOMKilled → alert fired → then agent investigation steps. The alert must appear before any evidence collection.
7. Consistent spacing: same padding in all cards, equal card heights in rows, nothing touching card edges. Check at 1280px and 768px widths.
